### Мой дипломный проект на курсе «Системный аналитик» в Яндекс Практикуме

В этом репозитории собраны финальные материалы моего выпускного проекта:
* `diploma_diagrams.drawio` — схемы бизнес-процессов (BPMN/UML).
* `database_structure.docx` — спроектированная структура таблиц и связей базы данных.
* `user_story_map.docx` — карта пользовательских историй проекта.
* `pmi_testing_plan.docx` — программа и методика испытаний (план тестирования).
* `figma_prototypes.docx` — описание и ссылки на визуальные прототипы интерфейса.
